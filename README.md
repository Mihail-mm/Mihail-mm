and building event-driven applications. I enjoy solving complex problems

## 💼 Experience

### 🛒 Ozon Tech — Software Engineer

Worked on a franchise management system for pickup points, developing
financial and operational features.

- Moved document signing from background monitoring to an event-driven
  architecture, improving processing efficiency by **85%**.
- Redesigned guaranteed payment calculations to support flexible periods.
- Automated tariff synchronization and worked on settlements in national
  currencies.

### 🤖 Kontur — Software Engineer

Built backend features for a voice assistant that calls customers.

- Designed and implemented a telephony management service and REST APIs.
- Developed automatic callback functionality, improving customer interaction
  efficiency by **50%**.
- Integrated the service with a recruitment system, helping reduce the time
  required to fill vacancies by **80%**.

### 🍽️ Master Soft — Software Engineer

Developed services for restaurant automation and reporting.

- Built microservices for collecting and aggregating sales and loyalty data.
- Integrated external payment providers and automated scheduled reports.
- Wrote unit, integration, and end-to-end tests for business-critical logic.
